01 · The idea

Print got the layout right. The web made everything else possible.

Pick up an old magazine, even a scanned one, and you already know how to read it. Feature on the left, photo on the right, pull quote breaking the column, ad in the corner. Every page is a set of boxes, and readers have understood that layout for a century.

Scans lose what the web does well: links, selectable text, search, sound, motion. The Take Economy keeps the magazine's layout and builds it on modern web tools. Issues are discrete and collectible, something you look forward to. And every page is live content, not a picture of one.

The name refers to the attention economy we all live in now, where a take spreads faster than the facts behind it. Our job is media literacy: helping readers agree on the facts first, then argue about what to do with them.

02 · Everything is a box

One building block. Every kind of story.

The box is the basic unit of the magazine. Each box type knows how to lay itself out. When we improve how dossiers look, every dossier in the archive improves with it.

Feature

Long-form reporting

The cover story. Columns, pull quotes, and images placed by the box's own layout rules.

Dossier

The receipts

Multi-source investigations with timelines and a citation block for every claim.

Interview

In their words

Conversations you can read, or play as the original audio.

Field note

From the ground

Short dispatches with a place, a date, and a point.

Video & audio

Embedded right

A vertical Short sits in a vertical box. Each box matches the shape of its source.

Gallery

Deep zoom

Planned: zoom in on any image box directly, without a pop-up.

Pull quote

The line that matters

One line from the story, set in its own box.

03 · Have it your way

Read it, watch it, or listen to it. You choose for each box.

Planned for phase 2. Presentation will be set on each box, not for the whole site: read the feature, listen to the interview on your commute, watch the field note. Every box will offer only the modes it can actually deliver.

Preview of a planned feature
Read

Selectable, searchable text with real links, typeset by the box's own layout rules.

Scroll turns the page

In progress. Scroll down for the next page, up for the previous one. You get the feel of flipping through an issue, and every page stays live and linkable.

Issues worth collecting

Each issue comes out complete, like a print edition, rather than as an endless feed.

Fast and findable

Every issue is built as static HTML that search engines can index. The page doesn't jump around while you read.

04 · The algorithm is a box

You'll see the algorithm. You'll be able to adjust it.

Planned for phases 3 and 5. In the archive, a story's size will reflect how much attention readers keep giving it. A three-year-old piece that people still read stays big. Stories nobody visits shrink. An editorial floor stops the most popular boxes from crowding out everything else. Until then, box sizes are editorial choices.

The ranking logic will be a box too, on the front page, where you can see it. It will list every signal we collect, and later you'll be able to adjust it.

  • Time spent on a story
  • Read, watch, or listen choice
  • Zoom interactions
  • Issue completion

What we don't collect: no third-party trackers and no cross-site tracking. We'll collect only the aggregate signals listed above, and until the attention engine ships we collect none of them.

Algorithm box · demo size = floor × attention

Example stories and made-up values. The real weights and decay curve haven't been set. The layout only changes when you move a control.
